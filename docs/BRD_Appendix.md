# BRD Appendix - 사내 규정 기반 연차 관리 시스템

## A. 문서 목적

본 문서는 [BRD](BRD.md)의 비즈니스 요구사항을 뒷받침하는 상세 기준을 정의한다. 사내 추가 연차 부여 규정, 적용 주기, 중복 처리 원칙, 부여 이력 항목 및 미결정 사항을 관리한다.

본 문서의 사내 규정은 서비스 기획과 구현 범위를 정의하기 위한 가상의 예시이다. 실제 회사에 적용할 때에는 인사 책임자의 승인과 별도의 법률·노무 검토가 필요하다.

## D. 공통 적용 원칙

1. 규정 충족 여부는 인사 담당자가 확인하고 적용 규정을 직접 선택한다.
2. 시스템은 선택되지 않은 규정을 자동으로 부여하지 않는다.
3. 시스템은 선택한 규정별 부여 일수와 총 부여 일수를 계산한다.
4. 저장 전 담당자가 선택 규정과 총 부여 일수를 확인한다.
5. 부여 결과에는 적용 당시의 규정과 처리 담당자를 함께 기록한다.
6. 규정 변경 시 기존 부여 이력은 변경하지 않고 적용 당시 규정을 유지한다.
7. 장기근속 규정의 근속기간은 법정 연차 산정과 구분되는 사내 복지 연차용 기준이며, 휴직기간을 제외한 인정 근속기간으로 계산한다.
8. 2월 29일 입사자의 장기근속 기준일은 윤년이 아닌 해에 2월 28일로 적용한다.
9. 각 연차 부여 규정은 독립적으로 적용한다. 한 규정의 대상에서 제외되더라도 다른 규정의 적용 여부에는 영향을 주지 않는다.
10. 출산장려와 다자녀 복지는 입사일로부터 3개월이 지난 날부터 적용한다. 대기기간 중 출산으로 요건을 충족하면 입사 3개월 도달일에 부여한다.
11. 우수 근태는 선발형 규정이 아니라 반기별 기준 충족형 규정이다. 해당 반기 전체를 휴직 없이 근무하고 부여 시점에도 재직 중인 직원만 대상으로 하며, 반기 중 입사하거나 휴직한 직원은 다음 반기부터 적용한다. 유연근무제는 없는 것으로 가정하고 근태 시스템에서 최종 지각 처리된 건만 집계한다. 부여는 반기 종료 후 근태 기록이 확정된 시점에 처리한다.
12. 모든 추가 복지 연차는 실제 부여일 현재 재직 중인 직원에게만 부여한다. 퇴사자에게는 소급 부여하지 않는다.

## E. 중복 부여 및 예외 처리

### E.1 중복 확인 기준

| 규정 유형 | 중복 확인 기준 |
|---|---|
| 도달 시 1회 | 직원 + 규정 |
| 분기별 | 직원 + 규정 + 연도 + 분기 |
| 반기별 | 직원 + 규정 + 연도 + 반기 |
| 연간 | 직원 + 규정 + 적용 연도 또는 입사일 기준 회차 |
| 사건 기준 1회 | 직원 + 규정 + 해당 사건 |

### E.2 예외 처리 원칙

- 중복 가능성이 있는 경우 저장 전에 담당자에게 알린다.
- 잘못 저장된 이력의 수정·취소 방식과 권한은 별도로 확정한다.
- 규정 적용에 필요한 정보가 불충분하면 담당자가 확인한 뒤 처리한다.
